# Jukeboox

Jukebox com ESP32, leitor RFID RC522 e DFPlayer Mini. Cada tag seleciona uma faixa ou playlist do cartão microSD. O painel da ESP32 mostra a faixa e permite ajustar o volume e avançar a reprodução.
